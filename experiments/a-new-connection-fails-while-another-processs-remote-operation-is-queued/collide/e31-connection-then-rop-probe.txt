# The reverse order of e1: B's probe of S's window is sent first and waits
# for S's busy UI thread; 5 ms later L's remote operation into the same
# window is queued behind it. Does B's connection still fail?
spawn S server
wait S hwnd
spawn L client $HWND L
send L init
wait L done
send L efh
wait L done
send L rop
wait L done 10000
spawn B client $HWND B
send B init
wait B done
send S busy 40
wait S busy-begin
send B async probe
sleep 5
send L ropname
wait L done 15000
wait B done 15000
drain 300
