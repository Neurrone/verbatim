# Section 20.10's warm-up. Each iteration starts three fresh client
# processes, in a rotating order: one that makes its UIA client and then
# probes and looks up S's window (cold, tags C); one that first probes and
# looks up a window of another process, W (warm-other, tags X); one that
# first probes and looks up a hidden window of its own (warm-own, tags N).
# The figures are the first probe of S's window and the lookup after it.
spawn S server
wait S hwnd
spawn W server
wait W hwnd
spawn C0 client $HWND C0
send C0 init
wait C0 done
send C0 probe
wait C0 done
send C0 efh
wait C0 done
send C0 quit
