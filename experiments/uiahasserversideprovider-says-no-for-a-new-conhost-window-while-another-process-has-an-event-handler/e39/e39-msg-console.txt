# e39 experiment 1 under the e38 trigger: L is a passive listener (its
# registrations and hook, nothing read); U, a fresh client, calls
# UiaHasServerSideProvider at DELAY after the console window is found,
# then the lookup. Hooks on every conhost thread log each WM_GETOBJECT and
# registered message conhost receives (hooklog/<conhost pid>.log). The
# hooks are installed just after the calls are sent (the thread snapshot
# takes about 18 ms, longer than conhost takes to first pump), so a
# message dispatched before they are in place is missing from the log.
spawn L listen L e39- passive
wait L listening 20000
spawn U client 0 U
send U init
wait U done
hook 0
fgright
console ${TITLE}
sleep ${DELAY}
send U target $HWND | send U probe | send U lookup
hook $CONPID
wait U done lookup 20000
drain 1500
closeconsole
drain 200
