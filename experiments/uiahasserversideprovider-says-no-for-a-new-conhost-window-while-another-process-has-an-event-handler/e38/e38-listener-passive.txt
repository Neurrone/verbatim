# e38 listener variant: as e38-listener, with L in mode passive (see e38.rs:
# passive = registrations and hook, nothing read; focusonly = the focus
# handler alone, no group, nothing else changed; grouponly = the root group
# alone, nothing read; nohook = no WinEvent hook; noread = the probe and
# console check but no remote focus read).
spawn L listen L e38- passive
wait L listening 20000
spawn U client 0 U
send U init
wait U done
spawn R client 0 R
send R init
wait R done
fgright
console ${TITLE}
sleep ${DELAY}
send R target $HWND | send U target $HWND | send R rawprobe | send U probe | send R efhbcd | send U efhbcd
wait U done efhbcd 20000
drain 1500
closeconsole
drain 200
