# e38 condition 1: as e38-alone, with L, a focus listener like Verbatim's
# (desktop registration: focus handler then the root group; a global
# WinEvent hook; per console focus event the provider probe and console
# check, once per window, then the remote focus read), listening before
# the console starts.
spawn L listen L e38-
wait L listening 20000
spawn U client 0 U
send U init
wait U done
spawn R client 0 R
send R init
wait R done
fgright
console ${TITLE}
sleep ${DELAY}
send R target $HWND | send U target $HWND | send R rawprobe | send U probe | send R efhbcd | send U efhbcd
wait U done efhbcd 20000
drain 1500
closeconsole
drain 200
