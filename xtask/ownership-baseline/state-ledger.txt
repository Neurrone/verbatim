# The ledger of long-lived state, which `cargo xtask ci` checks against the
# code (xtask/src/ledger.rs): every field of the structs and enums each
# root below reaches in its own crate, as `Type.field: type -- category`,
# under the heading of the file that declares it. The categories, and when
# each needs a reason after it, are listed in xtask/src/ledger.rs. A
# `known-copy` copies a fact another record owns; it is allowed only as
# xtask/ownership-baseline/known-copies.txt lists it, and that list only
# shrinks. `cargo xtask ownership --update-baseline` rewrites the lines
# from the code, keeping each category; comments are kept only here, above
# the roots.
