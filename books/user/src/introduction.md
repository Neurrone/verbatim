# Verbatim User Guide

This guide is for people using Verbatim, the screen reader. Most of it is not written yet.

## How this guide is organized

The guide has four parts, each answering one kind of question:

- [Tutorials](tutorials/readme.md) teach by walking you through something from start to finish.
- [How-to guides](how-to/readme.md) give the steps for one task.
- [Reference](reference/readme.md) lists the facts: commands, settings, messages.
- [Explanation](explanation/readme.md) explains how Verbatim works and why.

Within every part, pages are grouped by the same topics, in the same order, so what the guide says about one topic is found under the same heading in each part. A part lists only the topics it has pages for.

1. Getting started.
2. Reading and navigating.
3. Typing and editing.
4. Speech and voices.
5. Braille.
6. Settings and profiles.
7. Extensions.
8. Privacy and security.
9. Troubleshooting.
