# Tutorials

Each tutorial builds a working module from start to finish, in order of difficulty. They are drafts written against the API designed for milestone M5; their code becomes compiled examples, built and tested with Verbatim, once M5 is built.

1. [A fix made of rules: Notepad's go-to-line box](rules-only-fix.md): a module with no code, one rule and the focus report.
2. [A module with code: Calculator's result](calculator-result.md): a hook on a notification, reading the application's tree, and verdicts.
3. [A global module with a list dialog](global-module.md): commands that work everywhere, a double press, reading another application, a list dialog and a click.
4. [Packaging and installing an extension](packaging.md): the extension folder, zipping it into a `.vext`, and reading the install dialog.
