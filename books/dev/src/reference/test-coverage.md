# Test coverage

Every Verbatim gesture and user-facing feature, with the tests that cover it at each of three levels: unit and generated tests (a crate and the test's name), mockapp tests (`crates/mockapp/tests`, the backends against a scripted application) and end-to-end scenarios (`crates/verbatim-e2e/src/registry.rs`, a real Verbatim on a real desktop). The testing standard is [books/dev/src/reference/testing.md](testing.md); the milestones that close the gaps are in [the roadmap](https://github.com/Neurrone/verbatim/blob/main/docs/roadmap.md). A change that adds or removes a gesture, a user-facing feature or a test updates its row here, and moves the row between the gap tables and the area tables when a gap opens or closes. Gestures are given for the desktop layout, with the laptop layout's key after a comma when it differs; the layouts share one dispatch, which `key_reports` tests for both. Measure and demo scenarios are not tests and are not listed.
