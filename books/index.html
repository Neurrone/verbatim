Verbatim documentation

Verbatim is a screen reader for Windows 11, on x64 and ARM64, written in Rust.

User Guide

For people using Verbatim. Not written yet.

Development Guide

For people working on Verbatim itself: setting up, running the tests, the crates and their APIs, the architecture and the reasons behind its design.

Extensions Development Guide

For people writing extensions: app modules and speech engines. Written with milestone M5, when extensions arrive.

Status

Milestones are scoped by the risk each retires, not by date.

  • Complete: M0, foundations; M1, the self-voicing prototype; M2, the test harness and VM; M3, desktop usability core; M4.4, message types in their final home; M4.5, logic foundations; M4.6, generated tests.
  • In progress: M4, text, editing and terminals.
  • Next: foundation fixes from the retrospective of October and November 2026; then M5, extensions, and M6, the native synthesizer host and Eloquence.

The full roadmap and the source code are on GitHub.
