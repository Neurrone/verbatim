# NVDA captures

Recorded readings by NVDA, taken with `cargo xtask nvda capture`
([the NVDA transcript guide](../nvda-transcript.md)), kept where a later
change is checked against them.

- `verbatim-gui.txt`: NVDA reading Verbatim's menu and Speech settings
  dialog before the GUI port (phase 6, step 3), the reference for
  checking the port.

Captures used once to write a scenario's assertions are not kept here;
the scenario's module comment quotes what it relied on.
